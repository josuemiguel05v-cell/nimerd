Editor de episodios

Herramienta local para configurar vídeos que tengas autorización para publicar. No existe acceso administrativo a tu hosting desde aquí: este editor crea un archivo streams.json que debes sustituir en la carpeta data/.

No agregues enlaces a copias no autorizadas. Los vídeos deben ser tuyos, de dominio público o tener licencia de distribución. Recomendado: HTTPS y CORS habilitado.

Si ya tienes un archivo streams.json, selecciónalo para continuar editándolo.

3. Episodios configurados
